# JavaScript Practice

## Coding questions

1. Reverse a String:
Write a function that reverses a given string. For example, if the input is "hello," the output should be "olleh."
2. Palindrome Check:
Write a function that checks if a given string is a palindrome. A palindrome is a word, phrase, or sequence that reads the same backward as forward.
3. Factorial Calculation:
Write a function that calculates the factorial of a given number. The factorial of a non-negative integer n is the product of all positive integers less than or equal to n.
4. Fibonacci Sequence:
Write a function that generates the nth number in the Fibonacci sequence. The Fibonacci sequence is 0, 1, 1, 2, 3, 5, 8, 13, 21, and so on.
5. Array Chunking:
Write a function that takes an array and a chunk size as arguments and splits the array into chunks of the specified size.
6. Anagram Detection:
Write a function that checks if two words are anagrams of each other. An anagram is a word or phrase formed by rearranging the letters of another.
7. Title Case a Sentence:
Write a function that converts the first letter of each word in a sentence to uppercase.
8. Find the Missing Number:
Given an array containing n distinct numbers taken from 0, 1, 2, ..., n, find the one that is missing from the array.
9. Caesar Cipher:
Implement a function that takes a string and a shift value and returns a new string where each letter is shifted by the provided amount.
10. Deep Comparison:
Write a function that compares two objects and returns true if they are deeply equivalent (have the same values for the same keys).
11. Count Vowels:
Write a function that takes a string and returns the number of vowels (a, e, i, o, u) in the string.
12. Remove Duplicates:
Write a function that takes an array of numbers and returns a new array with duplicates removed.
13. Validate Palindrome:
Write a function that takes a string and returns true if it is a valid palindrome, considering only alphanumeric characters and ignoring cases.
14. Max Character:
Write a function that takes a string and returns the character that appears the most.
15. Capitalize Letters:
Write a function that takes a sentence and capitalizes the first letter of each word.
16. Sum of Two:
Write a function that takes an array of numbers and a target sum. Determine if there are two numbers in the array that add up to the target sum.
17. Merge Sorted Arrays:
Write a function that merges two sorted arrays into a single sorted array.
18. Reverse Words:
Write a function that reverses the words in a sentence. For example, "Hello World" should become "World Hello."
19. Intersection of Two Arrays:
Write a function that returns the intersection of two arrays, i.e., the elements that appear in both arrays.
20. Binary Search:
Implement a binary search function that takes a sorted array and a target value, returning the index of the target value in the array.
21. Smallest and Largest Numbers:
Write a function that takes an array of numbers and returns an array with the smallest and largest numbers.
22. First Non-Repeating Character:
Write a function that finds the first non-repeating character in a string.
23. Caesar Cipher (Advanced):
Modify your Caesar Cipher function to support both encryption and decryption.
24. Shuffle Array:
Write a function that shuffles the elements of an array randomly.
25. Valid Parentheses:
Write a function that takes a string of parentheses and determines if the order of the parentheses is valid.
26. Rotate Matrix:
Write a function that rotates an NxN matrix (2D array) 90 degrees.
27. Flatten Array:
Write a function that takes a nested array and returns a flat array.
28. Sum of Prime Numbers:
Write a function that calculates the sum of all prime numbers up to a given number.
29. Camel Case:
Convert a sentence to camel case. For example, "hello world" should become "helloWorld."
30. Two Sum:
Given an array of integers, return indices of the two numbers such that they add up to a specific target.
